# Create or resume a handoff

1. **Record the current state.** At the end of a session, update `handoffs/current.md` with the prompt completed, files created or changed, checks performed and their observed outcomes, remaining questions or approvals, and the next task. Link to details in `docs/verification.md` and use project-relative paths.
2. **Verify the state on resumption.** Read `handoffs/current.md`, `README.md`, and `AGENTS.md`. Confirm the root and check the reported files and Git status. Rerun the smallest relevant check from `docs/verification.md` before continuing with the next authorized task.
